# Jodyang — ระบบจัดการสวนยางพารา

เว็บภาษาไทยสำหรับจัดการสวนยางสวนเดียว ออกแบบสำหรับมือถือและคอมพิวเตอร์ ใช้ Tailwind CSS, Google Sheets เป็นฐานข้อมูล, Google Drive เก็บใบเสร็จ และมีคิวบันทึกออฟไลน์

## โครงสร้าง

- `src/` — หน้าจอ เมนู แบบฟอร์ม รายงาน การคำนวณ และคิวออฟไลน์
- `functions/api/` — API proxy ของ Cloudflare Pages เก็บรหัสเชื่อม Apps Script ไว้ฝั่งเซิร์ฟเวอร์
- `apps-script/Code.gs` — ตรวจบัญชีและสิทธิ์ บันทึก Google Sheets, Drive และประวัติการใช้งาน
- `public/` — ไอคอน เว็บแอป และไฟล์สำหรับเปิดใช้งานแบบ PWA

## ความสามารถที่เตรียมไว้

- บัญชีล็อกอินสร้างโดยแอดมินเท่านั้น แบ่งสิทธิ์เป็นแอดมิน คนกรีด และผู้ดูข้อมูล
- แอดมินจัดการบัญชี แปลง ผู้รับส่วนแบ่ง ค่าใช้จ่าย และรายการขาย
- คนกรีดเพิ่ม แก้ไข และลบบันทึกรอบกรีดได้
- ผู้ดูข้อมูลค้นหา ดาวน์โหลด Excel และพิมพ์หรือบันทึกเป็น PDF ได้ โดยไม่มีสิทธิ์แก้ข้อมูล
- รายการขายแยกจากรอบกรีด และลงน้ำหนักที่ขายแยกตามแปลงได้
- แบ่งรายได้หลายแปลงรวมตามผู้รับส่วนแบ่ง เช่น รวมสองแปลงของคนหนึ่ง แยกจากแปลงของอีกคน
- ค่าใช้จ่ายระบุยอดแยกตามแปลงได้ มีหมวดเริ่มต้นสำหรับน้ำ กรดยาง ภาชนะ มีด ลวด และยากันยุง
- ยอดสุทธิคำนวณจากยอดขาย ลบรายการหักจากผู้ซื้อ และลบค่าใช้จ่ายที่ผูกกับแปลง จากนั้นแบ่งตามเปอร์เซ็นต์ที่ตั้งไว้
- แนบสลิปเป็นรูปหรือ PDF ขนาดไม่เกิน 5 MB และเก็บไว้ใน Google Drive ส่วนตัวของเจ้าของระบบ
- เก็บประวัติการเพิ่ม แก้ไข และลบข้อมูลพร้อมชื่อผู้ทำรายการ
- ดูพยากรณ์ 3, 5 หรือ 7 วัน และรายชั่วโมง 24, 48 หรือ 72 ชั่วโมง พร้อมแจ้งเตือนฝนภายในเว็บ
- บันทึกการเปลี่ยนแปลงในเครื่องเมื่อเน็ตหลุด และส่งคิวเมื่อกลับมาออนไลน์

## รันในเครื่องผ่าน VS Code

ต้องติดตั้ง Node.js 20.19 ขึ้นไป และ npm ก่อน

1. เปิดโฟลเดอร์ `jodyang` ใน VS Code
2. เปิด Terminal แล้วรัน `npm install`
3. คัดลอก `.env.example` เป็น `.env.local` และใส่ URL Apps Script กับ `GAS_PROXY_SECRET` หลังตั้งค่าฐานข้อมูลเสร็จ
4. รัน `npm run dev` แล้วเปิด URL ที่แสดงใน Terminal

หากยังไม่ได้เชื่อม Apps Script หน้าเว็บจะเปิดได้ แต่ล็อกอินและบันทึกข้อมูลไม่ได้

## เตรียม Google Sheets และ Apps Script

1. สร้าง Google Sheet ใหม่สำหรับ Jodyang และอย่าแชร์ชีตให้ผู้ใช้เว็บโดยตรง
2. เปิด **Extensions → Apps Script** จากชีตนั้น
3. วาง `apps-script/Code.gs` ลงในไฟล์ `Code.gs` และแทนที่ manifest ด้วย `apps-script/appsscript.json` (เปิดการแสดง manifest ใน Project Settings หากยังไม่เห็นไฟล์)
4. เลือก `setup` แล้วกด Run และอนุญาตสิทธิ์ Sheets กับ Drive ระบบจะสร้างแท็บฐานข้อมูลและโฟลเดอร์ใบเสร็จ
5. เปิด **Deploy → New deployment → Web app** ตั้ง **Execute as: Me** และ **Who has access: Anyone** แล้ว Deploy
6. คัดลอก URL ที่ลงท้าย `/exec` ไว้ใช้ในขั้นตอนต่อไป
7. เปิดหน้า **Executions** ของ Apps Script แล้วดู log ของ `setup` คัดลอกค่า `GAS_PROXY_SECRET` ไปตั้งเป็น secret ฝั่งโฮสต์ และเก็บ `JODYANG_SETUP_KEY` ไว้สำหรับสร้างแอดมินคนแรก
8. อย่าส่งค่า secret หรือรหัสผ่านใน Git, แชตสาธารณะ หรือไฟล์หน้าเว็บ

ปลายทาง Apps Script เปิดรับคำขอจากอินเทอร์เน็ต แต่จะยอมทำงานเมื่อได้รับ `GAS_PROXY_SECRET` จาก API proxy เท่านั้น การอ่านข้อมูลทุกครั้งยังต้องมี session token ที่ระบบตรวจสิทธิ์ไว้

## เผยแพร่เว็บฟรีจาก GitHub

โปรเจกต์เตรียมไว้สำหรับ Cloudflare Pages ที่เชื่อมกับ GitHub:

1. อัปโหลดไฟล์และโฟลเดอร์ภายในโปรเจกต์นี้เข้า GitHub repository
2. ใน Cloudflare Pages สร้างโปรเจกต์จาก repository นี้ แล้วเว้น **Root directory** ว่างไว้ เพราะไฟล์เว็บอยู่ที่ราก repository (หากนำไปวางใน monorepo ให้ตั้งเป็น `jodyang`)
3. ตั้ง **Build command** เป็น `npm run build` และ **Build output directory** เป็น `dist`
4. เพิ่ม environment variables สำหรับ Production:
   - `GAS_WEB_APP_URL` — URL Apps Script `/exec`
   - `GAS_PROXY_SECRET` — secret จาก log ของ `setup` ให้ตั้งเป็น secret ไม่ใช่ค่าในไฟล์
5. Deploy แล้วเปิดเว็บครั้งแรก กรอก `JODYANG_SETUP_KEY` เพื่อสร้างบัญชีแอดมิน
6. หลังสร้างแอดมินแล้ว รหัสตั้งค่าเริ่มต้นจะถูกใช้ไม่ได้อีก

Cloudflare Pages ให้บริการไฟล์หน้าเว็บแบบคงที่ฟรี และคำขอ Pages Functions นับตามโควตา Workers Free ซึ่งปัจจุบันระบุ 100,000 คำขอต่อวัน โควตาและเงื่อนไขอาจเปลี่ยนได้ ดู [ข้อจำกัด Cloudflare Workers](https://developers.cloudflare.com/workers/platform/limits/) และ [ข้อจำกัด Google Apps Script](https://developers.google.com/apps-script/guides/services/quotas) ก่อนเปิดใช้งานจริง

## การใช้งานออฟไลน์และข้อจำกัด

- เว็บเก็บหน้าแอป ข้อมูลที่โหลดแล้ว และรายการรอซิงก์ไว้ในอุปกรณ์แต่ละเครื่อง
- เมื่อกลับมาออนไลน์และเปิดเว็บไว้ ระบบจะส่งรายการค้างให้อัตโนมัติ; ถ้าปิดเว็บไปก่อน คิวจะส่งเมื่อเปิดเว็บอีกครั้ง
- การเข้าสู่ระบบครั้งแรกต้องออนไลน์ การใช้แบบออฟไลน์ทำได้เฉพาะอุปกรณ์ที่เคยเข้าสู่ระบบและมีข้อมูลแคชแล้ว
- พยากรณ์อากาศต้องใช้อินเทอร์เน็ต และจะแสดงข้อมูลล่าสุดที่เคยโหลดเมื่อออฟไลน์
- พยากรณ์ใช้ Open-Meteo API ฟรีสำหรับการใช้งานส่วนตัว/ไม่เชิงพาณิชย์ และแสดงเครดิตตาม CC BY 4.0; หากนำระบบไปใช้เชิงพาณิชย์ ต้องเปลี่ยนไปใช้แผนหรือแหล่งข้อมูลที่อนุญาต
- การแจ้งเตือนฝนแสดงในหน้าเว็บ ไม่ส่ง SMS, LINE หรืออีเมล
- ค่าใช้จ่ายที่เลือกหลายแปลงต้องกรอกยอดเงินของแต่ละแปลงเอง เพื่อให้ยอดสุทธิและส่วนแบ่งตรงกับการจัดสรรจริง
- กำหนดเปอร์เซ็นต์ผู้รับส่วนแบ่งแต่ละแปลงให้รวม 100% ก่อนใช้ยอดคำนวณจ่ายจริง

## หลักการคำนวณ

สำหรับแต่ละแปลง ระบบคำนวณ:

`ยอดสุทธิแปลง = (น้ำหนักขายแปลง × ราคาต่อกิโลกรัม) − รายการหักจากผู้ซื้อที่เฉลี่ยตามน้ำหนัก − ค่าใช้จ่ายที่ระบุให้แปลง`

จากนั้นคำนวณส่วนแบ่งรายคนตามเปอร์เซ็นต์ของแต่ละแปลง และรวมหลายแปลงที่มีผู้รับและประเภทส่วนแบ่งเดียวกัน รายงานแสดงทั้งยอดก่อนหัก รายการหัก ค่าใช้จ่าย และยอดสุทธิ
